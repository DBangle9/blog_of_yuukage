圣瓦尔登大学城后街的霓虹灯牌一向坏得很有赛博朋克风格。

比如悬在诺拉头顶三米处的那块灯箱，原本写着**「蓝屏终点站 · 专业芯片级维修」**十二个大字，因为年久失修外加省电，眼下只有**「蓝屏 终 站 维」**五个字在冷雨里滋滋闪着惨白的电火花，看着不太像正经修电脑的地方。

诺拉·弗罗斯特把卫衣兜帽往下拉了拉，左手拎着两杯刚从街角买的七分糖去冰乌龙奶茶，右手推开那扇贴满褪色硬件海报的玻璃门。

门口的风铃早就锈死了，压根没响。

“老板娘，刚忘问你喝不喝芝士奶盖，顺路多买了杯——”

诺拉话说到一半，脚步忽然停住。

一股刺鼻的焦糊松香味混着热风枪的低鸣，从挂着半截碎花门帘的维修台后面飘了出来。更让她警觉的是，左手腕内侧藏在袖口里的皮肤，突然泛起一阵像被静电针轻扎了一下的细微刺痛。

作为一名拥有四分之一星裔血脉的混血儿——按如今网上那些营销号爱用的词，一个“混血小魔女”——诺拉这辈子没学会过半句正经咒语。别说像史书里那样呼风唤雨了，她拼尽全力集中精神，魔力输出的上限也就是把手里那杯冰奶茶从零度隔空捂成十八度半的温水。

但这份稀薄到近乎鸡肋的血脉，却给了她一项在电子工程系堪称外挂的怪毛病：她对高频数字电路的电磁谐波格外敏感。

好的高频芯片通电时，在她听觉边缘像是一段干净规整的节拍器；劣质山寨芯片或者虚焊短路的电容，听起来就像粉笔刮过黑板一样刺耳。

此刻，三米外的维修台上，她那台宝贝得跟命根子似的便携工作站正敞着底壳躺在防静电垫上——原本插在主板插槽里那两条让她吃了一个月泡面才攒钱买下来的**海力士原厂 A-die DDR5 内存条**，正散发出一种陌生又杂乱的高频噪声。

诺拉眯起那双隐隐透着灰蓝色的眼睛，放轻脚步，悄悄绕到了柜台侧面。

那位自称“技术过硬、童叟无欺”的年轻老板娘正背对着门口，整个人缩在一张磨掉皮的粉色电竞椅里。她穿着一件宽大到遮住大腿的黑色连帽卫衣，两条修长的小腿裹着蓝白相间的**程序员经典条纹过膝袜**，膝盖上还夹着一只被抱得有些瘪塌的宜家蓝鲨鱼玩偶。

留着柔顺浅栗色齐肩长发的老板娘戴着一对闪着呼吸灯的猫耳降噪耳机，右手捏着热风枪，左手拿着精密镊子，正小心翼翼地把一片印着高端品牌 Logo 的铝合金散热马甲，往一条光秃秃、留着打磨痕迹的廉价绿色内存板子上按，嘴里还压低嗓子小声念叨：

“对不起对不起……这位学妹真的对不起，贴纸没撕破、导热垫我也给你换了新的……你平时肯定就拿这电脑写写文档看看网课，用不到 6400 兆赫兹 C32 的时序对不对？借我这两条 A-die 去电子城周转两天交完电费，下个月一定给你买一对更好的装回来……林纳斯·托瓦兹保佑我千万别被发现……”

诺拉面无表情地把两杯奶茶往柜台边一放，上前一步，伸手在老板娘那只亮着粉灯的猫耳耳机上轻轻敲了两下。

“老板娘。”诺拉声音很平静，“林纳斯保佑不保佑你我不知道，但我现在很想知道，你手里那片马甲底下压着的，到底是个什么玩意儿？”

“哇啊——！”

一声吓劈了半个音的惊叫在店里响起。

老板娘整个人从电竞椅上弹了起来，手里的热风枪差点脱手，慌忙一把将膝盖上的宜家鲨鱼按在桌角那两条真正的原厂内存条上，严严实实地压进了鲨鱼肚子底下。

她摘下猫耳耳机转过身，一张画着淡妆、眉眼清秀的脸蛋涨得通红，下意识往下扯了扯宽松卫衣的袖口，挤出一个僵硬的营业微笑：

“哈、哈哈，学妹你回来得这么快呀！外面雨这么大，怎么不多逛一会儿？你的电脑我已经清完灰、换完霍尼韦尔相变片了，现在正在给你做内存金手指抛光和散热马甲加固呢！”

“是吗？”诺拉抱起双臂，顺着老板娘僵硬的右手，把视线移到了她正按在桌面上的那只蓝色毛绒鲨鱼上。

在鲨鱼圆滚滚的尾鳍底下，不偏不倚露出了半截墨黑色的高端电路板，以及一小角亮闪闪的**海力士原厂颗粒激光防伪码**。

“那麻烦老板娘解释一下，”诺拉拉开凳子坐到工作台前，顺手把老板娘已经装回去开机进系统的工作站转过来对着自己，“我来之前只是让你清个灰、查一下左声道电流声。怎么清完灰以后，我这台机子开机连内存自检都要转三圈？”

“那是正常的主板内存训练！DDR5 平台都这样，你别瞎猜……”老板娘硬着头皮辩解，穿着条纹袜的脚尖心虚地在地板上蹭了蹭。

诺拉懒得跟她废话。

她伸手敲下 `Ctrl + Alt + T`，在双系统里唤出一个半透明的黑色终端窗口，熟练地敲下一行命令：

```bash
sudo dmidecode -t memory | grep -E "Size|Speed|Manufacturer|Part Number"
```

回车。

老板娘脸上的血色在回车键落下的瞬间退了个干净。

黑底绿字的终端屏幕上，无情地滚出了四行回显信息：

```text
Size: 16 GB
Configured Memory Speed: 4800 MT/s
Manufacturer: Unknown (0x0000)
Part Number: NANYA-REJECT-GRADE-C-4800
```

屋子里安静下来，连窗外的雨声和屋后低沉的服务器风扇声都显得格外清晰。

诺拉侧过头，皮笑肉不笑地指了指屏幕：“`Manufacturer: Unknown`，`REJECT-GRADE-C`，降级黑片？默认频率还锁死在 4800 兆赫兹？老板娘，你这清灰服务还附带物理层降频啊？嫌我电脑跑太快容易吃超速罚单？”

老板娘张了张嘴，眼神往天花板和墙上那张卷了边的《如何正确退出 Vim》海报上乱飘。僵持了三秒之后，她突然腰板一挺，抱起桌上的宜家蓝鲨鱼挡在胸前，摆出了一副义愤填膺的架势：

“你先别掏手机报警！听我解释！”她清亮的声音拔高了八度，指着窗外远方市中心那座高耸入云、挂着蓝白色盾牌 Logo 的**圣盾智算（AegisTech）**大厦，痛心疾首地控诉道：

“这事儿难道能全怪我吗？！要怪就怪那帮存储大厂和 AI 算力巨头好不好！”

诺拉直接被这记甩锅整不会了：“……哈？你偷换我内存条，怪圣盾智算？”

“本来就是啊！”老板娘越说越来劲，抱着鲨鱼满肚子委屈，“你自己去看看今年的硬件行情！上半年三大存储晶圆厂隔三差五不是‘离奇起火’就是‘变电站停电’，下半年产能全切去给圣盾智算造 AI 超算集群用的 HBM 高带宽显存了！搞得消费级海力士 A-die 价格一路狂飙，一条原厂条的二手回收价都快赶上我半个月店铺电费加两盒处方药的钱了！”

说着说着，她的气势又迅速弱了下去，耳尖通红地小声嘟囔：

“再说了，我又没打算真吞你的……你这海力士 A-die 体质那么好，留在这台旧机器里天天看课件多浪费。我就想着先借去隔壁电子城押两天，把明天就要停电的电费窟窿堵上，等下周接了大单立刻给你赎回来嘛……这最多算是我向资本垄断发起的一次微小型物理层资产临时再分配！”

诺拉被气笑了。

她长这么大，在学校里见过拿大厂实习画饼的学长，在网上见过拿 AI 洗稿还不承认的营销号，还是头一回见到把“修电脑偷换顾客内存颗粒”说得如此充满反垄断悲情色彩的奸商。

“少给我扯什么资产再分配！”诺拉拍案而起，伸出右手，“大厂切产能割全联邦的韭菜，你就割我一个靠奖学金和泡面续命的大二穷学生？明天去实验室做预研仿真全指望这对内存条撑着呢！把我的 A-die 还我，就在你鲨鱼屁股底下压着呢！”

“哎呀小点声！街坊听见影响我口碑！”

老板娘慌忙伸手去捂，却忘了自己手里还抱着蓝鲨鱼。诺拉眼疾手快，探身越过摆满硅脂和螺丝刀的柜台，一把攥住了鲨鱼尾鳍下露出的一角黑色内存条。

“还我！”

“别拽别拽！那是静电敏感器件，没戴防静电手环会把颗粒击穿的——”

“你也知道是静电敏感器件，刚才用毛绒鲨鱼压着它的时候怎么没想到？！”

两人在窄小的柜台前拉扯成一团。

老板娘个子虽高，但常年熬夜写代码缺乏锻炼，手劲根本拗不过从小帮家里搬老旧暖气机的诺拉。她脚下一滑，“哎哟”一声向后仰倒，一屁股撞在了维修台后面那道隔断内外间的厚重遮光黑帘上。

“哗啦——哐当！”

老旧滑轨本就不牢靠，这一撞直接把整幅遮光帘连带后面靠墙堆着的快递纸箱全掀翻在地。

诺拉攥着抢回来的两条原厂海力士 A-die，刚想松口气，目光越过柜台往里一扫，整个人愣在了原地。

屋后那股低沉的风扇嗡鸣声一下子清晰了起来。

遮光帘后面藏着一个和外头这间破烂维修店截然不同的工作间。

三台高刷新率曲面屏呈环抱状支在木板桌上，上面跑着一套配色冷冽干净的 **Arch Linux + Hyprland 平铺窗口桌面**。左屏挂着密密麻麻的反编译汇编代码（Ghidra 界面里标满了寄存器跳转），中屏终端亮着淡紫色的 `fastfetch` 系统信息与自定义 Rust 脚本，右屏则开着一份还没写完的本地漏洞利用验证（PoC）文档。

桌子旁边立着一架快顶到天花板的二手工业机柜——里面塞了四台满载运转的退役双路至强 E5 服务器，五颜六色的网线垂下来，散热风扇呼呼作响，吹得旁边贴在迷你冰箱门上的几盒淡蓝色处方贴片包装盒（上面印着雌二醇透皮贴片的医学字样）和一排二次元立牌轻轻晃动。

更让诺拉停住呼吸的，是从倒塌的纸箱顶层滚落到她帆布鞋脚边的两样东西。

诺拉弯下腰，捡起了其中一件。

那是一枚沉甸甸的磨砂黑钛合金异形徽章，边缘刻着一圈断开的二进制编码环，正中央用激光蚀刻着两行在地下技术圈鼎鼎大名的字符：

**`RING-0`**
**`ID: V_Segfault`**

徽章旁边，压着一张有些发黄、用透明塑封膜仔细封好的科技周刊剪报。

标题印着一行醒目的黑字：
> **《最狂妄的三十天：匿名黑客组织「零环」成员 V_Segfault 连爆两大高危零日漏洞，手搓全链路攻击击穿“泰坦云”防御体系，千亿流氓巨头宣布退市重组》**

下方配图是三年前全网热搜第一的截图：靠往数千万用户主板里强塞监控驱动发家的 IT 巨头「泰坦云」官网被彻底攻陷，平时嚣张跋扈的 CEO 被逼得连夜挂出一张纯白底黑字的静态 `index.html` 道歉页，上面只有一行字——*“别打了，驱动我们立刻卸载，代码马上开源。”*

“……不是吧？”

诺拉捏着那枚微凉的黑色徽章抬起头，难以置信地看向正坐在快递纸箱堆里、手忙脚乱往回藏宜家鲨鱼的长发老板娘。

“你是……**`V_Segfault`**？！”

诺拉的声音都变了调：“三年前在著名黑客组织「零环」当核心主力、一个月挖出两个满分零日漏洞、手搓‘浏览器逃逸加内核提权加主板固件驻留’全套攻击链、一个人把泰坦云干到退市关门的那个传奇黑客……**段错误小姐**？！”

坐在纸箱堆里的老板娘动作僵住了。

她看了看诺拉手里的磨砂黑钛合金徽章，又低头看了看怀里差点被捏扁的蓝鲨鱼，脸上那副心虚的奸商表情一点点收了起来。

她慢慢站起身，拍掉卫衣上的灰尘，伸手理了理有些凌乱的长发，清了清嗓子——清亮软糯的声线因为刚才受惊微微沉了半度，很快又稳回了平时那种带着几分傲气的女声。

“眼神挺尖嘛，小同学。”薇薇安·林抱起双臂，下巴微抬，努力在一地纸箱和廉价热风枪之间端出几分世外高人的架子，“不错，薇薇安·林，以前的代号确实叫 `V_Segfault`。都是年轻不懂事时干的旧事了。”

诺拉还没从冲击里缓过神来：“等等……泰坦云当年悬赏五百万信用点找你，暗网论坛现在还有人拿你那条攻击链当教材研究！你这种级别的大神，怎么会缩在大学城后街修电脑，还为了两条海力士 A-die 跟一个大二学生耍心眼？！”

“外行人懂什么。”薇薇安叹了口气，手指漫不经心地卷着一缕发尾，望向窗外的细雨，语气沧桑，“干黑客这行整天跟黑产和资本家打交道，太累了。姐姐我当年早就赚够了一辈子花不完的钱，已经彻底金盆洗手退出「零环」了。现在开这家店，纯粹是为了体验人间烟火，堂堂正正靠双手修电脑赚干净钱——顺便过点平静日子。”

说着，她冲诺拉挑了挑眉：“刚才那纯属是一时手痒的职业习惯，想考考你们现在的工科大学生懂不懂底层硬件校验。恭喜你通过测试，这次清灰给你打九折，一百八，扫码还是现金？”

诺拉眨了眨眼。

要是忽略她刚说完“赚够了钱”时嘴角那一下不自然的抽动，这番宣言听着还真挺像那么回事。

直到诺拉的视线扫过柜台角落——那里压着几张崭新的红色催缴单。

就在诺拉刚想开口的下一秒——

*嗡！嗡嗡！*

薇薇安扔在防静电垫上的二手裂屏手机震动起来。屏幕亮起，弹出一条自带语音播报的系统强提醒短信：

> **【奥瑞利安联邦电网 · 最终停电通告】**
>
> 尊敬的商户（户名：林薇薇安 / 蓝屏终点站）：您本月商铺用电量已达 **1,420 千瓦时**，累计欠缴电费 **1,842.60 信用点**（已逾期 47 天）。因多次催缴未果，系统将于 **24 小时后（明日晚 20:00）** 执行远程强制拉闸断电！

维修店里一时鸦雀无声。

薇薇安脸上那副“财务自由退隐高人”的淡然微笑僵在了嘴角。

偏偏就在语音播报刚念完“强制拉闸断电”六个字的时候，帘子后面那架塞着四台双路 E5 洋垃圾服务器的机柜突然传出一声闷响。墙角那只九块九包邮买来的杂牌排插冒出一缕青烟，过载保护开关“啪”地跳闸弹开。

整间「蓝屏终点站」一下子陷入了黑暗。

三台 Arch Linux 曲面屏黑了，机柜风扇停了，门外只剩五个字的破霓虹灯箱也灭了，只有排插上那颗微弱的红色故障灯还在黑暗里一闪一闪。

诺拉站在原地沉默了三秒。

她抬起左手，掌心上方半寸处悄然浮起一缕淡薄的**银蓝色微光**，顺手帮柜台边那两杯快冷透的乌龙奶茶维持在了温和的 **`18.5℃`**。

借着这点银蓝色的微光，诺拉把柜台角落压在泡面桶底下的账单看了个清楚：
- 商铺房租欠缴通知：逾期 1 个月。
- 电子城配件铺赊账条：欠款 630 信用点。
- 近十五天收款记账本：第一页写着“给楼下王大爷装系统收 20 元（大爷嫌贵砍成 10 元）”，第二页到第十五页——**全是空白**。

“……金盆洗手？”诺拉借着微光，看向黑暗里抱着宜家鲨鱼一动不动的传奇黑客，“赚够了一辈子花不完的钱？”

薇薇安把脸埋进蓝鲨鱼的肚皮里，发出一声闷闷的哀叹：

“……那些灰产赏金和加密货币来路太脏，退出「零环」那晚我全匿名捐给开源基金会和跨性别互助诊所了行不行！剩下那点合法存款，谁知道二手市场上四台双路 E5 配 256G 内存卖那么便宜，我一时没忍住全拉回来搭机房，结果这玩意儿光待机就吃八百瓦电！再加上正经药房的雌激素贴片和抗雄药又不给走基础医保……谁知道大学城这帮学生现在电脑坏了全找线上官保，半个月连个重装系统的单子都没有啊！”

一口气把老底全抖落干净后，这位曾经让千亿巨头闻风丧胆的漏洞大神彻底放弃了挣扎，蹲在纸箱堆旁抱着鲨鱼小声嘟囔：

“行了，你想报警就报吧。反正看守所包吃包住不用交电费，听说还能借书看，正好把我没看完的那本《Linux 内核深度解析》补完……”

预想中的报警电话并没有响起。

黑暗里响起一阵书包拉链拉开的声音。

诺拉收起掌心的微光，摸到门口总闸前，“咔哒”一声把没受影响的照明支路推了上去。昏黄的节能灯闪了两下，重新照亮了这间逼仄凌乱的小店。

薇薇安茫然地抬起头——等等，刚才黑暗里这姑娘手心发光是怎么回事？

她还没想明白，“啪”的一声轻响，一个厚实的牛皮纸信封，连同一杯温热适口的乌龙奶茶，被稳稳放在了她面前的防静电垫上。

“这里面是两千五百信用点。”诺拉双手撑着柜台边缘，灰蓝色的眼睛在灯光下亮得很，“是我这学期的全额奖学金，加上下个月的生活费。够你把欠供电局的一千八百四十二块六毛交清，剩下六百多块够买这个月的药、交网费，顺便给咱俩加几个鸡腿。”

薇薇安愣住了。她看看那个牛皮纸信封，又抬头看看诺拉：“……学妹，你这是干嘛？想让我帮你写毕业设计？先说好，代写论文违背开源精神，而且你刚才手里发光那个——”

“四分之一星裔血脉的相场反应。”诺拉坦然地把那杯温奶茶往前推了推，“现在网上管我们这种人叫‘混血魔女’。放心，我连块冰都烧不开，顶多帮你把奶茶捂到十八度半。”

薇薇安眨了眨眼。常年混迹互联网底层，她对“异类”的接受度比普通人高得多——第一反应居然眼睛一亮：

“真的假的？那你刚才摸一下主板就知道我换了降级黑片，合着你天生自带频谱分析仪啊？！那以后修主板查短路岂不是一摸一个准？”

诺拉嘴角抽了抽，把跑偏的话题拽回正轨，从书包夹层里抽出一张卷了边的旧复印件。上面是一张模糊的黑白照片，拍着三十八年前圣瓦尔登旧电磁楼 B204 地下室里的一对年轻男女，底下用红笔圈出了一个如今在主流搜索引擎里已被屏蔽的名字：

**艾弗琳·拉文希尔（Evelyn Ravenhill）。**

“我不用你帮我写作业，也不准你再去换别人的内存颗粒。”诺拉认真地说，“我拿这笔钱雇你——平时我还可以帮你看店拉客赚电费。作为交换，我要你出山，跟我干一票大的。”

薇薇安低头看着那张旧照片，收起了玩笑神色：“……你想干什么？涉黑涉暴的勒索软件我不碰。”

“我要找当年窃取艾弗琳研究成果拿去造武器、害她被抹去名字流放三十八年、现在还在全网抹黑魔女的那帮军方机构算账——顺便会一会他们背后那群把内存和显卡炒成天价的混蛋。”

诺拉在灯光下冲她伸出了右手：“怎么说，零环大神，这单活儿接不接？”

店里安静了片刻。

薇薇安低头看了看那张标红的停电通知单，又看了看旧照片，最后目光落在那杯刚好 `18.5℃` 的乌龙奶茶上。

她叹了口气，把宜家蓝鲨鱼往怀里拢了拢，伸出沾着一点导热硅脂的手指，轻轻握住了诺拉的手。

“丑话说在前头啊，混血小魔女。”薇薇安挑了挑眉，“第一，直接黑军方内网这种找死的事儿，给多少钱我也不干——明天上午先给你补一节网安常识课，免得你连什么叫物理隔离都不知道就拉着我去踩缝纫机。”

“第二，”她顺手把那个装满两千五百信用点的信封揣进怀里，弯起眼睛笑了，“光靠店里这台刚跳闸的老机柜可干不成大事。明早交完电费，先跟我去电子城看看行情——还有，这两杯奶茶算老板娘预支的入伙福利，谢啦！”
