两分钟后，那台标价两万八千信用点的全侧透海景房主机，被平平整整抬上了防静电维修台。

薇薇安戴上蓝色丁腈手套，捏着电动螺丝刀卸下最后一颗钢化玻璃侧板螺丝，一边取下玻璃，一边诚恳地问面前的男生：“小兄弟，你确定你是隔壁艺术学院的大一新生，没在哪个硬件测评区兼职做毁灭电子产品整活博主？”

名叫杰森·莫里斯的银发男生搓着手，急得快哭了：“姐，我真没整活！我平时开直播打竞技游戏，昨晚打到一半掉帧，弹幕全说我水冷液不行、涂硅脂太抠门。有个挂着十级粉丝牌的老哥私信我，说往冷排里兑半瓶冰红茶——带个‘冰’字导热快还能防冻——再把硅脂挤满插座就能稳两百四十帧！我寻思十级老粉总不能害我吧……”

旁边的诺拉忍不住吐槽：“十级老粉确实不害命，但能让你破财。”

玻璃侧板一拿开，焦糖红茶被高温熬煮后的甜酸味混着元件烧焦的糊味扑面而来。

薇薇安低头往机箱里看了一眼，深吸了一口气。

那套 360 分体水冷亚克力硬管里晃荡着半管浑浊的茶褐色液体，冷头叶轮里卡着一层黏糊糊的糖霜；拆掉冷头后的主板 CPU 插座更惨不忍睹——密密麻麻的镀金针脚被整整两大管灰白色硅脂糊得严严实实，平得像刚抹完腻子的墙面，连半根针脚都看不见。

薇薇安用镊子挑起一点硅脂凑到台灯下看了看，转头问杰森：“你买的这管硅脂，包装上是不是写着‘超频专用、高含银微粒’？”

杰森连连点头：“对对对！店家说含银导热好，我挑最贵的买了一百八一管！”

“恭喜你。”薇薇安闭了闭眼，“高含银硅脂是**微导电**的。正常人拿它薄薄涂在处理器金属顶盖上填缝隙，你直接灌进一千多根针脚里，等于给这颗五千块的处理器炖了一锅短路乱炖。再加上含糖冰红茶受热顺着接口漏到了供电模组上——你开机时没把机箱炸开花，全靠电源保护电路拼命拉住了。”

杰森脸色发白：“那岂不是全报废了？！硬盘里还有我下周要交的剪辑作业和五杀素材没备份呢！官方售后看了一眼就让我花一万四换全套……”

“先别慌。”一直在旁边观察的诺拉开口安抚道，“固态硬盘装在最底下的独立插槽里，没沾到冰红茶，你的作业肯定没事。至于主板和处理器——给我们两个小时，你先去街角咖啡店坐会儿，留个电话，修不好分文不收。”

杰森连声道谢：“好好好！只要能救活保住数据，两千块维修费我一分不砍，修完我还去校园群和直播间帮你们宣传！”

送走杰森，店门重新关上。

薇薇安看着桌上这台“冰红茶海景房”，把额头抵在桌沿上叹气：“两千块要少了……光把插座针脚里的导电硅脂洗干净还不弄弯针脚，就够我眼睛看花的，洗完还得对着几千个贴片元件一个个拿万用表查短路……”

“查短路的活儿不用你费眼。”诺拉挽起袖子，把无水洗板水和防静电软刷递进她怀里，“你负责清洗和微焊，找哪颗元件烧了交给我。”

二十分钟后，两人的第一次配合就显出了奇效。

薇薇安干起正经活来手艺确实没得挑。她拆空水冷管路，用蒸馏水循环冲净冷排，又把主板放进超声波清洗槽配合洗板水洗了两遍，拿软毛刷顺着针脚倾角一点点挑净残余硅脂，最后进恒温箱烘干。一番收拾下来，原本糊成一片的插座恢复得锃亮如新，一根针脚都没歪。

接下来是最费工夫的一步——冰红茶滴进供电区烧穿了贴片元件，常规流程得翻点位图挨个测对地阻值，少说要耗两三个小时。

“把稳压电源调到 1 伏、限流 1 安培，接上主板总供电。”诺拉戴好防静电手环坐到主板前，闭上了眼睛。

薇薇安依言接好电源按下开关，电流表指针立刻顶满，说明主供电确实存在对地短路。

诺拉没碰万用表，只是伸出左手悬在电路板上方两厘米处，从左上角慢慢移向右下角。在她的感知里，原本平稳的电路谐波中混进了两道尖锐刺耳的杂音。

不到三秒，诺拉睁开眼，指尖停在两处极小的贴片区域上方：

“左上角第三相核心供电，DrMOS 芯片左边第二颗 0201 褐色小电容击穿了；还有内存供电区边缘这颗四脚小电感旁边的滤波贴片也哑了。其他地方很干净，核心和显卡插槽都没事。”

薇薇安半信半疑地拿起万用表调到蜂鸣档，把细表笔搭在诺拉指出的第一颗芝麻大电容两端。

“滴——”

蜂鸣声响起，读数跳出 `0.001 Ω`，死短路。

她手腕一挪，又测了诺拉指出的第二处内存区贴片。同样是对地短路，而周围紧挨着的十几颗元件阻值全部正常。

薇薇安手里的表笔停在半空，摘下头戴式放大镜，上下打量了诺拉一番：

“……诺拉，我收回昨天说你血脉鸡肋的话。”薇薇安由衷感叹，“不用热成像仪、不用熏松香、不用翻点位图，手一挥三秒钟揪出两颗 0201 短路电容？有你坐镇，咱俩去电子城摆摊半年都能买房了！”

“少做梦，赶紧焊好上机测！”诺拉嘴角微扬，催促道，“干完这单就能先把编程器赎回来了。”

随后的四十分钟轮到诺拉看呆了。

认真起来的薇薇安完全没了平时抱鲨鱼耍赖的散漫劲儿。左手镊子稳如机械，右手热风枪控在 360 度轻扫取下坏件，换上料板拆下的同规格电容，一点助焊膏轻触即合，显微镜下的焊点圆润漂亮得跟原厂流水线做出来的一样。

换上纯净水冷液，贴好相变导热片，装机通电。

“咔哒——嗡……”

机箱里六把风扇同时亮起流光，水泵轻响，主板自检绿灯顺利跳过。不到十秒，显示器跳出了熟悉的系统桌面——杰森那几个标着“下周作业终极版最终不改版.prproj”的文件夹安然无恙。

半小时后赶回来的杰森看着满血复活、烤机温度还降了八度的主机，激动得握着手机当场扫过来 **两千五百信用点**：“多出五百请两位姐姐喝奶茶！我这就回直播间和电竞群夸爆你们店！”

诺拉笑眯眯地挥手送客，冷不丁听见身后的薇薇安张开了嘴：

“对了老弟，你打游戏掉帧多半是因为 Windows 后台遥测太占资源，下次有空抱过来，姐姐免费帮你刷套精简版 Arch Linux……”

诺拉眼疾手快，反手一把捂住老板娘的嘴，笑着把一脸茫然的杰森推出门外：“哈哈她开玩笑的！打电竞别装 Linux，反作弊报错会哭的！慢走常来啊！”

关上门，诺拉松开手瞪她：“店规第二条写上去才三小时！你想明天被电竞社提着键盘来拆店吗？”

薇薇安揉了揉嘴小声嘟囔：“……Proton 兼容层跑单机明明已经很顺滑了嘛……”

事实证明，一个大学游戏主播的口碑传播比贴一万张传单都管用。

周六下午三点起，「蓝屏终点站」迎来了开业以来头一回客流小高峰。

先是两个计科学长抱来一台开机两分钟就降频卡顿的游戏本——拆开底壳一看，散热口堵了一层厚得能擀毡子的灰，学长自己加装的固态硬盘散热片底下，那张印着红字 **`REMOVE BEFORE USE（使用前请撕除）`** 的塑料膜压根没撕。

接着又来了一位在直播间花六千八买了台“i9 级电竞神机”的大一新生。薇薇安拧开侧板看了一眼，当场开启了毒舌模式：

“烈士墙经典套餐啊这是！十年前的退役 E5 洋垃圾配寨板，电源是连铜牌认证都没有的‘红星炸弹’，显卡是矿场拉出来翻新的残血卡——你这六千八里头，也就前面这六把跑马灯风扇值三十五块钱！”

骂完，薇薇安盯着那块老主板眼珠一转，小声跟诺拉商量：“不过这颗 E5-2680v2 成色还挺新，要不等他退货麻烦，咱三百块收来塞机柜……”

“啪。”诺拉拿空胶带卷轻轻敲了下她的脑门，“醒醒，再往店里搬电老虎，下个月供电局直接来拆电表了。”

忙活了整整两天，两人一共接了十一单活儿。

周日下午快打烊时，隔壁设计学院一个女生取完修好排线的笔记本，临走前笑着夸了一句：“老板娘今天扎丸子头配黑卫衣真好看，修电脑又不坑人，以后我们宿舍电脑都来你这儿修啦！”

薇薇安愣了一下。等女生出门，这位平时嘴硬的传奇黑客耳尖悄悄红了一点，摸了摸发尾，嘴角弯起了个浅浅的弧度。

诺拉假装没瞧见，低头打完计算器，合上账本舒了口气：

“汇报好消息，周末两天总营收 **五千一百二十信用点**！扣掉还王老板的六百三十块配件欠款、下月房租定金、你的处方药钱和咱俩的饭钱，账上净剩 **三千八百多块**！”

“发财了！”薇薇安抓起钥匙起身，“走，趁电子城没关门，先把编程器和逻辑分析仪赎回来，顺便买两根新灯管把门口招牌修好！”

---

周日晚上九点半。

后街门口换了新灯管的招牌完整亮起了青白色的光——**「蓝屏终点站 · 专业芯片级维修」**。

卷帘门拉下一半，店里只开着暖黄色的鹅颈台灯。两杯热可可冒着热气，这次诺拉特意坐得离薇薇安的杯子远了点。

刚花八百块赎回来的**通用高压编程器（T48）**已经连在了 Arch Linux 主机上。防静电垫中央放着那块老电路板 `B204 - Proto - 04`。

“深呼吸，小魔女。”薇薇安神情专注起来，戴上放大镜，用恒温热风枪配合低温锡膏，将那颗沉睡了三十八年的 28 脚陶瓷 **紫外线擦除 EPROM（27C256）** 稳稳拆了下来。

她用玻璃纤维笔轻轻擦去管脚上的氧化层，确认遮光贴纸完好无损，随后将芯片放进编程器锁紧插座，扣下压杆。

“先做好心理准备。”薇薇安手指搭在回车键上，转头看了诺拉一眼，“EPROM 靠浮栅电荷存数据，过去三十八年了，就算全部漏光读出一堆 `0xFF` 空白字节也很正常。”

诺拉攥着衣角点点头：“嗯，读吧。哪怕还剩一行字也是赚。”

薇薇安敲下读取命令：

```bash
minipro -p "AT27C256R@DIP28" -r b204_proto04_dump.bin
```

编程器上的红灯快速闪烁起来。屋里只剩下服务器轻微的风声。

终端进度条一点点爬到尽头：

`Reading Code...  100%  OK!`
`32768 bytes read in 1.42 seconds.`

“芯片没坏！”薇薇安精神一振，立刻敲下十六进制查看指令。

前几千个字节果然出现了电荷衰减留下的 `ff ff ff ff` 空白断层。诺拉心里一紧。

“别急，往下看！”薇薇安快速翻页，“高地址区有数据！超过七成的扇区电荷都保住了！”

切入字符扫描与反汇编窗口后，跳过前面几百行坏块，终端中央清晰地跳出了一段完整的纯 ASCII 文件头注释。

屋里安静下来。诺拉凑近屏幕，轻声念出了那几行跨越了三十八年的字符：

```text
==================================================
ECHO_LOG_V04 // ST.VALDEN B204 LAB
AUTHORS: E. RAVENHILL & C. VANCE
TARGET_RESONANCE   = 142.8 Hz
CHIRAL_TORSION_ANG = +11.4 DEG
HARD_POWER_LIMITER = 382 mW  [DO NOT BYPASS!!]
NOTE: 0.37ms lag halo kept intentionally.
      18.5C is warm enough for milk.
==================================================
```

“……`18.5C is warm enough for milk`。”

诺拉念着最后那句注释，眼眶有些发酸，“历史书和 AegisGPT 骂她是想毁灭人类能源的疯子。可三十八年前，他们连写进芯片死代码里的功率上限都锁死在三百八十二毫瓦，还特意标了两个感叹号不许绕过限幅器。他们真的只是想在冬天捂热一杯牛奶。”

旁边的薇薇安没吭声，已经把这 32KB 固件拖进了左屏的 Ghidra 反编译工具里。一行行八位单片机汇编指令迅速展开成控制流图。

看了足足半分钟，平时看谁代码都嫌烂的薇薇安长吐了一口气：

“……神人啊。”

诺拉转头问：“代码损坏很严重？”

“恰恰相反，写得太漂亮了。”薇薇安指着屏幕上的查表跳转，眼里满是佩服，“三十八年前的八位工控单片机没有浮点运算单元，全部空间才 32KB，搁现在连张手机缩略图都存不下。这个叫卡特尔的老哥硬是用定点数移位和手算查表，把艾弗琳推导的 `+11.4°` 手性偏置实时锁相逻辑塞进了不到四百行代码里。”

她转过电竞椅面向诺拉，笑了起来：“最关键的是——**咱们拿到做亲子鉴定的‘基因样本’了！** 这种独特的算法常数和定点数截断习惯就像指纹一样，就算圣盾后来用现代 C++ 包了八层壳，只要核心物理模型没换，反编译一对比准能抓个现行！”

诺拉兴奋地问：“那我们下一步直接买张圣盾显卡拆开比对吗？”

薇薇安翻了个白眼：“大姐，一张新款旗舰 Aegis-RTX 9090 黄牛价两万六，咱账上这三千八连个散热器都买不起！先好好开店等机会，在那之前，咱可以先去圣盾官网下他们的免费闭源驱动练练手。”

说着，薇薇安的视线慢悠悠落在了桌角诺拉那台贴着贴纸的笔记本电脑上。

诺拉下意识把电脑往怀里护了护：“干嘛？海力士 A-die 我已经贴封条了啊！”

“谁还惦记你内存。”薇薇安嘿嘿一笑，从兜里掏出一枚银色 U 盘，外壳上用黑记号笔写着一行字：

**`Arch Linux ISO (Rolling)`**

“既然你是我的技术搭档了，以后天天要拆圣盾的闭源驱动和遥测包，你机子里那个装满校园网流氓客户端的 Windows 和乱糟糟的旧 Ubuntu 可不能用了。”薇薇安晃了晃 U 盘，“备份好论文——姐姐今晚手把手带你从零命令行手搓 **Arch Linux 配 Hyprland 桌面**！”

诺拉看着那枚 U 盘，心里隐隐觉得不妙：“等等……现在十点多了，我明天早八还有《数字电子技术》实验课点名呢……装这个应该很快吧？不会出什么奇怪的报错吧？”

薇薇安搂住怀里的宜家蓝鲨鱼，拍着胸脯保证：

“放心！有我坐镇能出什么岔子？区区分区、装内核加配桌面，顶多半小时搞定，绝对不耽误你明天早八！”

彼时还很单纯的诺拉信了这句鬼话，乖乖交出了自己的笔记本电脑。

她当时还不知道，对于一位坚称“顶多半小时搞定”的 Arch Linux 信徒来说，面对一台搭载了双显卡与闭源专有驱动的笔记本电脑，这句承诺的含金量，基本等同于存储大厂发誓今年晶圆厂绝对不会失火。
