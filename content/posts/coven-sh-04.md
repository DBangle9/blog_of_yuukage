周日晚上十点十五分。

诺拉盘腿坐在旧折叠椅上，怀里捧着一桶刚泡好的老坛酸菜面，发呆似的盯着自己面前的笔记本电脑屏幕。

平时挂着壁纸和图标的高分屏眼下漆黑一片，只有左上角闪着一行冷冰冰的白色光标：

```text
root@archiso ~ # _
```

“……老板娘。”诺拉拿塑料叉子指了指屏幕，“图形安装界面呢？就是点‘下一步’、勾选‘我同意协议’、再看进度条走完的那种窗口，怎么没有？”

“图形向导那是给新手准备的拐杖！”

薇薇安坐在旁边的粉色电竞椅里，两条裹着蓝白条纹过膝袜的腿搭在机柜边沿，怀里夹着宜家蓝鲨鱼，端着半罐冰魔爪指点道：

“真正的极客，系统每一块砖都得从 `root@archiso` 黑框框里亲手敲命令砌出来！连自己装了哪些包都不清楚，怎么好意思叫黑客搭档？来，第一步先连店里 Wi-Fi，敲 `iwctl`！”

诺拉放下泡面，老老实实在键盘上敲下人生第一串 Arch 安装指令，直到屏幕弹出密码提示：`Passphrase:`。

诺拉抬头问：“店里 Wi-Fi 密码多少？”

薇薇安头也不抬地刷着论坛，随口报出一串乱码般的字符：“大写 `I`、小写 `l`、数字 `1`、零、大写 `O`、感叹号、艾特、井号、`Segfault`、下划线、九、零、小写 `l`、大写 `I`……”

三分钟后。

看着屏幕上第三次弹出的 `Operation failed`，外加店里那块廉价无线网卡抽风刷出来的掉包报错，诺拉深吸一口气站起身，拔掉桌角旧打印机背后的蓝色网线，“咔哒”一声插进了自己笔记本的网口里。

`ping archlinux.org` —— 延迟 `12ms`，通了。

诺拉拍拍手坐回凳子上：“网线直连才是爹。下次再设这种三十位大小写混排密码，我就把你路由器刷成砖。”

薇薇安噗嗤乐了：“觉悟挺高，已经领悟网络排障第一定律了。下一步 `cfdisk` 分区，看准硬盘编号，别把你存着实验报告的 Windows 分区给格了。”

诺拉顿时紧张起来。好在薇薇安上手时很稳，从空闲盘符里利索地划出两百个 G，建好根分区、交换分区和挂载点，一气呵成。

接着到了拉取基础系统包的一步：`pacstrap /mnt base linux linux-firmware`。

回车敲下，终端进度条慢得像蜗牛爬，右侧下载速度显示着一个让人绝望的数字：

**`14.2 KiB/s` —— 预计剩余时间：`3 小时 48 分钟`**。

诺拉嘴角抽了抽：“……这就是半小时搞定？”

“默认源连到冷海对岸去了，别慌！”薇薇安接过键盘，三秒钟把镜像源列表最顶端换成了**圣瓦尔登理工学院开源软件镜像站**。

再次回车，校园网千兆专线直接飙到 `88.5 MiB/s`，满屏软件包飞快滚过，不到一分半钟全部装完。

诺拉眼睛亮了起来：“这么快！看来十一点前真能回宿舍睡觉！”

薇薇安得意地扬起下巴，把电脑推回她面前：“那是！现在进 `arch-chroot` 改语言配置。自己动手才有仪式感——敲 `vim /etc/locale.gen`，把 `en_US.UTF-8` 和中文前面的井号删掉，保存退出！”

诺拉照做了。

屏幕刷出几百行灰字。诺拉移好光标，伸手按下了退格键想删掉 `#` 号。

屏幕毫无反应。

她皱了皱眉，又连按了几下退格和字母键。左下角冷不丁跳出一行红字提示，扬声器还“嘟嘟”响了两声。诺拉下意识想去按平时用惯的 `Ctrl + S` 保存，整个终端直接卡死，连光标都不动了。

诺拉慌了神，连按 `Ctrl + C`、`Esc`、`Alt + F4` 想关掉窗口，底部状态栏只冷冷弹出一行英文提示：

`Type :qa! and press <Enter> to abandon all changes and exit Vim`

“老板娘！键盘坏了！”诺拉举起双手离开键盘，“按删除不删字，按保存直接死机，刚才按了两下 `d` 还把我整行字吞了！这编辑器怎么连个退出叉号都没有？！”

旁边的电竞椅上，薇薇安抱着蓝鲨鱼笑得直拍扶手：

“哈哈哈恭喜诺拉同学，成功触发计算机史经典难题——**《如何活着退出 Vim》**！”

她笑够了才凑过来解围：“Vim 默认是普通模式！你刚按 `Ctrl + S` 触发终端锁屏了，按 `Ctrl + Q` 解开，按 `i` 才能打字，改完按 `Esc` 敲 `:wq` 保存退出！”

诺拉盯着这个像上世纪电报机一样的编辑器直咬牙：“我要装 `nano`！底下明明白白写着保存和退出快捷键的那个！”

薇薇安捂住胸口一脸痛心：“住口！在 Arch 圈子里说自己用 `nano` 是要被开除教籍的！听话，敲 `:wq`！”

折腾了五分钟、顺便学会用 `u` 键撤销误删后，诺拉总算战战兢兢写完主机名、设好密码、装完引导程序。

挂钟指向 **23:45**。

薇薇安满意地拔下银色 U 盘，抱起双臂退后半步：“虽然出了点小插曲，整体还是很顺利的。敲 `reboot` 重启吧！”

诺拉松了口气敲下重启。主板 Logo 亮起，又暗下去。

两秒后，黑漆漆的屏幕左上角浮出了三行白字：

```text
error: file '/boot/grub/x86_64-efi/normal.mod' not found.
Entering rescue mode...
grub rescue> _
```

屋里一下子静得可怕。

诺拉缓缓转过头，看了一眼快指向**零点**的挂钟，又转回来盯着笑容僵在脸上的薇薇安。

“……`grub rescue`？”诺拉轻声问，左手边的空气隐隐泛起一点静电感，“老板娘，顺便问一句——我存着明早八点数电实验报告的 Windows 引导项，现在还在吗？”

“咳咳！小失误，纯属手滑！”薇薇安额头冒汗，一把抓过 U 盘重新插回去，手指在键盘上敲得飞快，“刚才中途重启忘了重新挂载 `/boot/efi` 分区，把引导装进空目录了！而且新版 GRUB 默认关了 `os-prober` 没扫出双系统，文件肯定都在，一根毛都没少！”

“林薇薇安！”诺拉差点把空泡面桶扣她头上，“说好的半小时进桌面呢？！现在都零点十五了，连壁纸的影子都没见着！”

“五分钟！我拿蓝鲨鱼担保，五分钟必修好！”

蓝鲨鱼的信誉总算比存储大厂靠谱些。重新进救援环境挂载分区、开启双系统探测、重生成配置，十五分钟后重启，黑底白字的菜单里终于稳稳并排出现了 **`Arch Linux`** 和 **`Windows Boot Manager`**。诺拉这才把悬着的心放回肚子里。

“看吧，稳得很！”薇薇安松了口气，麻利地敲命令装好 **Hyprland** 平铺合成器、状态栏和独立显卡闭源驱动 `nvidia-dkms`，把自己的美化配置拷了过去，“五分钟后，让你见识见识什么叫真正的桌面美学！”

凌晨一点二十分，两百多个依赖包全部装完。薇薇安在终端敲下启动命令：

```bash
Hyprland
```

回车。屏幕黑了下去。

“第一次加载黑两秒很正常……”薇薇安话音未落。

第八秒，屏幕“滋啦”闪出一片刺眼的白噪点，左上角卡死一只硕大的白色鼠标箭头，下半截屏幕开始高频上下抽搐闪屏。想按快捷键切回命令行，键盘灯直接灭了，整台机器彻底死机，只能长按电源键强行断电。

凌晨一点二十五分，两个人并排呆坐在笔记本前，一时相顾无言。

“啪！”

薇薇安拍案而起，踩着条纹过膝袜站在地砖上，气得对着窗外夜空竖起了中指：

“**去他大爷的 NVIDIA 闭源驱动！还有那帮死活不肯好好做 Wayland 显存同步的硬件大厂！** 当年林纳斯在演讲台上对着镜头竖中指真是神预言！笔记本双显卡切个桌面都能黑屏死机，他们驱动部门平时是用脚写代码的吗？！”

看着平时总端着架子的大神气得跳脚，诺拉原本满肚子的早八怨气反倒一下子散了。她噗嗤笑出声，拿过旁边的灰色抓绒外套递给薇薇安，又拆了一包新泡面去烧水：“行了老板娘，披件衣服别冻着。今晚还有救吗，还是要偷偷给我装回 Windows？”

“装回 Windows？不可能！”薇薇安披上外套坐回三联屏前，较上了真，“三年前两个内核 0-day 我都啃下来了，今天要是栽在一张笔记本显卡驱动上，明天我就把店招牌摘了去卖烤红薯！泡面给我加根肠，今晚死磕到底！”

接下来的一个半小时，诺拉见识了一场堪比玄学的**赛博炼丹**。

薇薇安在自己屏幕上开了七八个 ArchWiki 页面和内核报错帖，往引导配置和环境变量里填进一长串天书般的参数：

- `nvidia_drm.modeset=1`
- `nvidia_drm.fbdev=1`
- `LIBVA_DRIVER_NAME=nvidia`
- `GBM_BACKEND=nvidia-drm`
- `__GLX_VENDOR_LIBRARY_NAME=nvidia`
- `WLR_NO_HARDWARE_CURSORS=1`……

改一轮、重编内核镜像、重启黑屏；查日志发现开源 `nouveau` 驱动没拉黑跟闭源驱动冲突了；拉黑再重启，又卡在门户权限包上。

凌晨两点半，两人头挨着头挤在台灯下吃泡面。诺拉看着薇薇安顶着黑眼圈一边敲命令一边小声念叨“这次千万别挂了”，忍不住笑出了声：

“薇薇安，网上那些营销号老说我们混血魔女念咒语不科学。可你看你凌晨两点半穿着条纹袜抱只鲨鱼，对着一堆 `modeset=1`、`fbdev=1` 念念有词，还得祈祷更新别把系统滚挂……你们 Linux 圈这手炼丹术，比魔女施法玄学多了好吧！”

薇薇安敲键盘的手一顿，自己也没忍住笑趴在桌上：“少贫嘴，这叫理解计算机底层的必经之路！所有暗坑都填平了，来，见证最后一击！”

**凌晨三点十八分。**

回车落下，黑屏只闪了半秒。

没有噪点，也没有撕裂。一幅带着细碎银蓝星光的深色极简壁纸，顺着 **144 赫兹** 刷新率平滑地铺满屏幕。

薇薇安按下 `Super + Q`，一个带毛玻璃半透明效果的终端窗口轻巧弹开；再按一下，两个窗口沿着黄金比例自动并排对齐，顶部的 `Waybar` 状态栏干净地显示着处理器温度、风扇转速，以及那行让诺拉安心的内存参数——**`DDR5 6400 MT/s (Hynix A-die)`**。

诺拉试着敲了几下切换快捷键，几个窗口行云流水般滑动让位，开机内存占用还不到 700MB。

“……真顺滑啊！”诺拉由衷感叹，“比原来那个开机弹广告、动不动后台偷跑更新把风扇吹得乱响的 Windows 舒服太多了！”

“我就说你会真香吧！”薇薇安顿觉扬眉吐气，敲下 `fastfetch` 亮出蓝白三角标志，掏出裂屏手机咔嚓拍了张照，累得把脑袋轻轻靠在诺拉肩膀上，懒洋洋地说：

“恭喜出师。从现在起你也是高贵的 Arch 用户了，明早去教室记得把终端开全屏，云淡风轻地跟前排同学说一句 `I use Arch, btw`。”

诺拉笑了笑，没躲开肩头那颗带着柑橘洗发水味的脑袋。她端起桌边凉透的白开水，左手贴着杯壁捂到温热，递给嗓子发干的薇薇安：“喝口温水吧，这回特意给你捂的。”

薇薇安接过暖融融的玻璃杯喝了一口，紧绷的肩膀放松下来。

凌晨三点半的小店很安静，窗外远处老教堂的尖顶隐在薄雾里。

“其实刚才本来能直接给你装个现成发行版省事的。”薇薇安看着干净的屏幕，声音轻了下来，“以前在「零环」的时候，我看过太多大厂在闭源系统里藏脏东西了。在他们的黑箱里，你的硬件归他们管，你在网上能看见什么历史、该讨厌哪类人，也全由他们说了算。我讨厌被人塞进黑箱里贴标签——不管是因为性别，还是因为血脉。”

她转头看向诺拉，眼神温和：“至少在咱俩一行行敲出来的这台机器里，每一行代码都干干净净，只听咱们自己的话。”

诺拉心里一暖，伸手轻轻碰了碰薇薇安握着水杯的手背：“嗯，这通宵熬得值——就是早八得靠两杯冰美式救命了。”

“趁热打铁！”薇薇安放下水杯拍了拍新系统，“拿它干第一票侦查——把**圣盾官网**公开的 **Linux 版显卡驱动包**拉进沙箱里解开，拿昨天读出来的 `ECHO_LOG_V04` 特征码扫一遍！”

诺拉精神一振，敲下 `curl` 从圣盾开发者页面拖下了那个足足 **680MB** 的闭源驱动包 `Aegis-GPU-Driver-Linux-x86_64.run`，加上 `--extract-only` 参数将里面的二进制模块与固件全拆了出来。

薇薇安跑起写好的五十行特征扫描脚本。

五秒后，先跳出一串不出所料的流氓遥测代码——驱动后台每隔三十秒就会偷偷扫描一次用户主板序列号往圣盾云端发心跳包。紧接着，脚本停在了 `/firmware/phase/` 目录下。

那里躺着一个 18MB、经过高强度硬件加密的固件包 **`aegis_phase_ctl.fw`**。而在负责加载它的开源垫片层符号表里，打包的外包程序员显然忘了把调试符号剥离干净，终端上清清楚楚跳出了三个函数名：

```c
aegis_phase_load_fw()
rc_chiral_mask_apply()
rc_legacy_037_suppress_enable()
```

凌晨四点，两个人同时屏住呼吸盯着屏幕。

“**`rc`……Ravenhill - Carter（拉文希尔-卡特尔）！**”诺拉声音微颤，“还有 **`chiral`（手性）** 和 **`037_suppress`（0.37 遮罩抑制）**！他们连函数前缀都没改干净，专门写了函数来盖住那道 0.37 毫秒的双环光晕！”

“抓到尾巴了！”薇薇安眼睛发亮，随即又皱起眉，“不过光凭三个函数名，圣盾法务肯定会狡辩说 `rc` 是 `Runtime Control` 缩写。我们得把那个 18 兆的 **`aegis_phase_ctl.fw`** 加密核心固件解开才行。可它是靠芯片内部私钥在片上硬件解密的，死文件根本破不开——除非弄一张真正在跑的圣盾旗舰显卡，趁上电自检解密进总线的那一瞬间，拿逻辑分析仪探针截获明文！”

诺拉苦了脸：“一张 Aegis-RTX 9090 黄牛价两万六，咱账上才三千八，上哪儿弄去啊？”

话音刚落，桌角诺拉的手机突然连震了好几下。

诺拉吓了一跳，划开屏幕一看，竟是夜猫子富二代主播**杰森**发来的一串救急私信：

> **【杰森】**（04:05）：学姐！老板娘！救命啊！
>
> **【杰森】**（04:05）：我刚把家里花两万六抢来的全新 **圣盾 Aegis-RTX 9090 旗舰显卡** 装机打通宵排位，刚进决赛圈，机箱里突然冒了股焦烟直接黑屏了！
>
> **【杰森】**（04:06）：圣盾官方客服看了一眼照片，说我之前主板进过冰红茶拒保，换新要我再掏一万八！天一亮我就把卡抱去店里，求两位姐姐再救我一次！

两人盯着手机屏幕面面相觑。

过了两秒，薇薇安对着桌上亮着蓝白 Arch 标志的笔记本合十拜了拜：

“看来林纳斯他老人家今晚真显灵了，两万六的旗舰卡自己长腿送上门来了……快定闹钟睡三小时，等你下完早八课回来，咱们开拆！”
