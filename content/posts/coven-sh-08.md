“等等，外套先别急着穿。”

诺拉刚抓起背包准备出门，薇薇安伸手拉住了她的卫衣帽，神色重新谨慎起来。

“怎么了？去晚了万一那位 `K.P.` 喝完酒走了怎么办？”诺拉回头问。

“网安圈第一条保命常识——**天上掉下来一块写好端口和接头地点的馅饼，先看看里头有没有藏鱼钩。**”薇薇安坐回三联屏前敲开终端，“万一这串零宽字符是圣盾安全部或者国安局设的**蜜罐（Honeypot）**呢？咱们傻乎乎跑去七号烧烤摊，烤架后面跳出来八个壮汉，正好一锅端。”

诺拉缩了缩脖子：“差点忘了还有钓鱼这回事！那怎么验真假？”

“看他留的那个 `8443/metrics` 测试服接口里写了什么。”薇薇安挂上四层匿名跳板，向那个端口发去一条普通健康检查请求，“大厂安全团队搭蜜罐都规规矩矩的，可演不出五年 996 真社畜那股子怨气。”

半秒后，一串 Prometheus 格式的监控指标刷了出来。

诺拉凑过去扫了一眼指标名称，没忍住噗嗤乐了：

```text
# HELP truthshield_bot_bullshit_generated_total 累计生成的昧良心AI水军废话总数
truthshield_bot_bullshit_generated_total{target="witch_smear"} 14829304

# HELP marcus_thorne_white_suit_saint_index 老板穿白西装装圣人时的自我膨胀指数
marcus_thorne_white_suit_saint_index 999999.0

# HELP promised_stock_options_real_value 入职时副总裁画的期权大饼当前实际价值(信用点)
promised_stock_options_real_value 0.0001

# HELP coffee_to_hair_loss_conversion_ratio 本月咖啡摄入量与发际线后移换算比
coffee_to_hair_loss_conversion_ratio 4.20
```

页面最底下还留了一行不起眼的注释链接，指向开源代码平台上一个归档个人仓库——作者 **`KevinPark-Dev`**，最后一次提交停在三周前，留言只有三个词：`Fine. I quit.`

`Echo-0.37` 很快弹出了核查结果：

> **`Echo-0.37 >`** 核实完毕，100% 真社畜！此人名叫**凯文·帕克（Kevin Park）**，29 岁，前圣盾智算推荐算法与内容安全部高级工程师，三周前刚赶上公司裁员毕业。这股子电子怨气，影帝来都演不出来！

薇薇安放心合上笔记本，套上百褶短裙和防风长风衣，把长发利落地束成高马尾，冲诺拉扬了扬下巴：“稳了，真内鬼。走，去老城区请客撸串！”

晚上八点半，圣瓦尔登老城区夜市街。

青石板路上映着各色招牌灯光，空气里飘着孜然、炭火烤肉和冰扎啤的香气，露天矮桌旁坐满了下班聚餐的人，热闹又踏实。

顺着油烟味走到街角老梧桐树下，两人一眼就看见了挂着红灯笼的**「老刘家七号烧烤摊」**，也一眼就认出了角落那张油腻塑料桌旁的目标人物。

那是个满脸胡茬、戴着黑框眼镜的年轻男人。身上套着件洗起球的灰色冲锋马甲，左胸原本印着圣盾智算蓝白盾牌和“五周年卓越员工”字样，被人拿黑马克笔涂成了一坨卡通大便；头上反扣着棒球帽遮挡发际线，脚边摆着六个空绿啤酒瓶。

这会儿他正盯着桌上那台旧款小红点 ThinkPad 笔记本，两手在键盘上乱按，嘴里借着酒劲嘟囔骂街：

“……平时在公司写 Python 全用集成环境，今晚喝高了手贱非要在终端里拿 `Vim` 改申诉简历……左下角怎么跳出来个 **`recording @a`**？！按了啥键进宏录制了？怎么退不出去啊！草，刚写的项目经历怎么全变成一排 `aaaaaaaa` 了！”

站在三米外的诺拉听乐了，转头幽怨地瞥了薇薇安一眼：“你看，二十九岁的大厂高级工程师照样在烧烤摊被 `Vim` 折磨。”

薇薇安忍着笑，冲摊主大叔喊了一声：“老板，角落那桌加两打冰扎啤、二十串羊肉、十串烤腰子、两份烤茄子，算我们账上！”

说完，两人在角落塑料桌前拉开红塑料凳，一左一右坐了下来。

正跟 `Vim` 较劲的凯文茫然抬起头。借着昏黄灯光，他看看左边扎着马尾、眼神清亮的学院风姑娘，又看看右边穿长风衣、眉眼精致的高挑长发美女，酒一下子醒了小半，下意识护住破电脑往后缩了缩：

“呃……两位拼桌吗？要是推销健身卡或者空气币的，我刚被裁员，卡里余额比发际线还惨，真没钱……”

诺拉笑出了声。

薇薇安从刚端上来的冰桶里拎出两瓶挂着水珠的啤酒，“啪啪”用打火机底座撬开瓶盖，推了一瓶到凯文手边。接着她探身点了一下凯文的键盘，顺手敲下 `Esc`、`q`、`u`——屏幕上那串灾难性的 `aaaa` 立马撤销干净了。

凯文一愣：“哟，懂行啊……”

薇薇安抬起眼，压低声音念出了那串暗语：

“**‘真理之盾水军引擎 v4.2，996 逼迫下写成。如果解开了这串零宽字符，恭喜，你比我的副总裁聪明多了。’**——顺便说一句，凯文·帕克先生，你忘关的那个 `8443` 端口现在还亮着呢，老板穿白西装装圣人的膨胀指数九十九万九千九。”

“咣当！”

凯文手里的酒瓶一抖，差点磕在盘子上。他酒意全消，按着桌沿左右瞄了一圈街口，压低嗓子紧张道：

“你、你们到底谁啊？！圣盾法务部派来的商业调查员？！我先声明，竞业协议没规定不许在测试服留调试指标！那串零宽字符是我那天发烧测编码敲错的乱码！”

“真要是圣盾法务部的，还能请你吃二十串羊肉加两打啤酒？”诺拉好笑地给他夹了两串刚烤好的羊腰子，“踏实吃吧。今天下午在「极客之眼」发帖质疑圣盾显卡、结果活了八十九秒就被你那套水军系统摁死的人，就是我们俩。”

凯文愣住了，看看大二学生模样的诺拉，又看看气定神闲喝啤酒的薇薇安：“下午那个 **`PhaseWatcher_185`** 是你们？！你们真拿十六进制把水军评论里的零宽隐写扒出来了？我当时就是随手泄愤埋的，压根没指望真有人能扫出来啊！”

“谁说我们是普通网友了？”

薇薇安放下酒杯，从风衣内袋里摸出那枚磨砂黑钛合金徽章，在昏暗灯光下亮了一秒便收了回去。

在圣盾内容安全部干了五年、天天研究顶级白帽黑客案例的凯文看清那行 **`RING-0 // V_Segfault`** 的瞬间，差点从塑料凳上滑下去。

“我靠？！”凯文赶紧捂住嘴，隔着镜片难以置信地压低声音，“**`V_Segfault`？！「零环」的段错误大神？！** 三年前一个月连挖两个满分 0-day 把泰坦云干退市、把我们圣盾安全部吓得停掉年假查了半个月服务器后门的传奇黑客——**居然是个这么年轻好看的漂亮姐姐？！**”

他揉了揉眼睛：“不对啊，以前圈里传闻不是一直猜 `V_Segfault` 是个五十岁秃顶的隐世老大叔吗？！”

听到“年轻好看的漂亮姐姐”，薇薇安耳根微红，受用地甩了一下高马尾，嘴角微扬：

“算你有眼光。那帮人靠刻板印象瞎猜了三年，活该摸不到我的边。正式认识一下——薇薇安·林，旁边这位靠星裔血脉帮我抓到圣盾芯片铁证的搭档，诺拉·弗罗斯特。”

凯文低头看了一眼自己胸口涂掉标志的纪念马甲，憋了整整三周的闷气一下子找到了出口。他抓起冰啤酒灌下半瓶，擦掉嘴角泡沫，把酒瓶重重往桌上一放：

“行！不用多说了！只要你们打算把马库斯·索恩那个穿白西装装圣人的伪君子、还有我那帮拿开源代码套壳洗白还用 AI 害人的前领导拉下马，这顿酒我认了！夜市人杂，找个没监控的地方，我把「真理之盾」底下的死穴全给你们倒出来！”

两人相视一笑，举杯碰了一下他的绿瓶子。

“成交！”薇薇安起身结账，顺手帮凯文合上旧电脑，“走，去大学城后街的**「蓝屏终点站」**，顺便介绍第四位伙伴给你认识。”

凯文跟着往街口走，好奇问：“第四位伙伴？也是以前「零环」退隐的高手？”

诺拉回头冲他一笑：“是个住在四十四 G 魔改矿卡里、最爱点评别人发际线的四比特本地大模型。”

凯文下意识按住了头上的棒球帽：“……现在退酒还来得及吗？”
