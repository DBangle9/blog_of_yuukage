三人赶回大学城后街的「蓝屏终点站」，反手把卷帘门拉下锁好。

凯文包都顾不上摘，跟着诺拉和薇薇安一起凑到了开放式矿架的主控屏前。终端窗口里，`Echo-0.37` 已经把刚解出来的 **第三层遮罩模块** 与 **第二层隐藏寄存器** 并排展开了。

> **`Echo-0.37 >`** 先看第一桩大乐子——那个占了整整三成固件体积的遮罩函数 `rc_legacy_037_suppress_enable()`。

薇薇安双手搭上键盘，只扫了二十行反编译出来的伪代码，表情就变得十分精彩：“……这就是卖两万六的旗舰显卡里藏着的‘核心黑科技’？”

诺拉和凯文凑过去顺着注释往下看，很快就看明白了这桩荒唐事——

由于芯片最底层的上古核心代码沿用了艾弗琳与卡特尔的锁相逻辑，只要芯片正常通电运转，微缩铋铜微环就会自然浮现出 **`0.37ms` 歪斜银蓝双环光晕** 与 **`142.8Hz` 大提琴泛音**。

圣盾高层当年显然怕得要命——要是几百万游戏玩家晚上关灯打游戏，看见自家侧透机箱里亮起歪斜蓝环还拉起了大提琴，“纯人类自研”的招牌当场就得砸烂。

底层代码动不得，他们便花钱找外包驱动团队在微码中层硬套了一个“反向噪声遮罩模块”：每隔一百毫秒申请一块 4MB 的显存环形缓冲区，往微环里反向灌入高频杂波，硬把大提琴泛音盖成普通显卡的电感电流声，把银蓝双环压灭。

最让人哭笑不得的地方，在这段函数的第 418 行：

```c
// 外包赶工版：每 100ms 申请 4MB 缓冲发射反向杂波遮盖 0.37ms 双环
void* mask_buf = vram_dma_alloc(4 * 1024 * 1024);
inject_antiphase_static_noise(mask_buf);
if (gpu_power_state == RESUME_FROM_IDLE) {
    return; // <-- 此处提前返回，漏写了 vram_dma_free(mask_buf)！
}
vram_dma_free(mask_buf);
```

薇薇安拍着额头笑出了眼泪：“我真是服了！全联邦几百万玩家和渲染工作室骂了整整三年、每次切屏待机再切回游戏就爆显存闪退蓝屏的陈年顽疾——官方客服推诿了三年，总赖玩家杀毒软件冲突或者电源瓦数不够。结果真相居然是他们请外包写遮羞布代码盖住艾弗琳的蓝环时，**外包老哥在休眠唤醒分支里漏写了 `free()` 释放显存指针？！**”

凯文也跟着乐不可支：“光漏显存还不算，为了全天候往芯片里灌反向杂波盖住蓝环，每张卡平白无故浪费了 **5.3%** 的有效算力和十几瓦废热！怪不得玩家总抱怨圣盾显卡风扇吵、温度高！”

诺拉眼睛一亮，飞快盘算道：“那反过来想——要是我们写一个几 KB 的干净小补丁，跳过这个遮罩函数，顺手把漏写的内存释放补上、把外层那个限制普通玩家显存带宽的软锁也解开……”

“那可就不止是让几百万台机箱同时亮起蓝环拉大提琴了！”凯文打了个响指，“等于顺手替全网玩家**免费修好了官方摆烂三年的显存泄漏蓝屏 Bug，还白送 5% 以上的游戏帧率提升和降温降噪！**”

他学着马库斯的口气比划道：“到时候就算马库斯在台上喊‘魔女黑客投放了恶意病毒’，底下的游戏玩家能当场把他喷回去——*‘黑客免费帮我修好蓝屏、降温度、白涨帧率，机箱还送绝版蓝环灯效，圣盾管这叫病毒？求黑客以后每个月给我发一回！’*”

> **`Echo-0.37 >`** 凯文哥这笔账算得精明！到时候都不用咱们宣传，游戏玩家为了这白送的 5% 帧率，能主动把咱们的小企鹅队徽供起来！

笑过之后，薇薇安收起笑容，敲回车切到了第二层加密区——**`HIDDEN_REG_0xAE91`**。

屋里的气氛随之凝重下来。

屏幕上是一份由三层椭圆曲线签名锁住、刚被借着初始化总线流撬开的底层寄存器指令表，顶端的宏定义标着一行醒目的英文：

**`AEGIS_BREAK_OVERRIDE // HIGH-GAIN PHASE-CANCELLATION MODE`**
*（破穹超载协议 // 高增益相消干涉武器模式）*

诺拉盯着这行字，声音压低了些：“圣盾在商用显卡和数据中心算力卡里，到底留了什么？”

薇薇安拉动滚动条逐行核对完阈值，神色冷峻：“正常民用状态下，芯片能量限制在机箱内部做相变导热，对人体和外界完全安全。但只要通过高速数据中心光纤，向成千上万张圣盾超算卡同时下发一段经**双私钥签署的军用激活指令**，这个隐藏寄存器就会绕过全部民用安全上限（`HARD_POWER_LIMITER_BYPASS`），把整座 AI 数据中心上万张显卡的微环同步锁相，**直接并网拼成一座城市级的相消干涉武器阵列。**”

凯文听得后背发凉，摘下眼镜擦了擦冷汗：“我在软件部干了五年，真不知道硬件部敢干这种事！《冷海停战协定》明文严禁部署破穹类武器，这是重罪啊！”

“在军营里建发射塔目标太大，所以索恩家族和军方采购部里的强硬派合起伙来暗度陈仓。”薇薇安冷声道，“打着建民用 AI 超算中心的名义拿走巨额补贴、包圆晶圆产能炒高硬件价格，背地里却拿民用算力卡搭起了一座随时能切换模式的影子军火库。”

诺拉握紧了拳头。所有线索全都串起来了——圣盾之所以花重金养水军抹黑艾弗琳、强推《相控生物识别法案》把星裔混血儿排挤出电子与科研行业，除了掩盖剽窃旧账，更是害怕对高频谐波敏感的混血儿接触硬件底层，听穿他们藏在商业芯片里的秘密。

“三十八年前他们偷偷拆掉艾弗琳的限幅器去炸星穹城，三十八年后又骗着全联邦普通人，把武器开关藏进每一块商业芯片里。”诺拉抬头看向两人，眼神清亮坚定，“绝对不能让他们就这么混过去。”

“所以咱们也得守住一条铁规矩。”薇薇安敲下几行命令，将 `AEGIS_BREAK_OVERRIDE` 的具体激活参数彻底加密封存进离线冷盘，严肃地叮嘱两人，“当年卡特尔公开罪证时特意剥离了武器参数防止扩散，今天咱们也一样——**武器化触发指令绝不能外泄半个字节。** 我们推送的纯净补丁，必须在固件层把 `HIDDEN_REG_0xAE91` 这个后门寄存器永久焊死在安全锁止状态；至于定他们的罪，咱们直接去把马库斯和军工高管签字的秘密采购合同偷出来！”

凯文长舒一口气，冲她竖起大拇指：“想得周全。跟老板娘干活心里踏实。”

诺拉走到墙边白板前，用红笔划掉今天的日期。白板顶端的倒计时还剩最后 **10 天**。

凯文推了推眼镜，梳理出最后两步任务：

“不碰物理隔离的军方内网，要在十天后的直播现场打出‘AI 反水念罪证 + 十万水军倒戈 + 全国机箱亮蓝环’的连招，咱们还差最后两把钥匙：第一，挖穿圣盾官方驱动自动更新客户端 **`AegisLink Updater`** 的热更新通道；第二，打通我之前提过的商用云推理网关 **`Aegis-InferProxy-v3.8.2-rc1`**，摸进 `ts-internal-archive-readonly` 审查知识库拷出那 1,428 份原档铁证！”

薇薇安没有半点犯难的意思，反而从椅子后面翻出一双洗得干干净净的压箱底紫白条纹过膝袜晃了晃，戴好猫耳耳机，活动了一下手腕：

“诺拉，门口挂上‘闭关停业两天’的牌子，去便利店搬两箱冰魔爪回来；凯文，把 `v3.8.2-rc1` 的路由结构图画给我当路标——退隐三年手都生了，接下来四十八小时，带你们看看怎么连挖两个零日漏洞！”
