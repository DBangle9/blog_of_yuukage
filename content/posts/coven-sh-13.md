周四清晨，「蓝屏终点站」玻璃门上贴出了一张诺拉拿快递纸箱剪出来的停业告示：

> **【闭关通知】**
>
> 店主闭关研究驱动底层美学，暂停接单 48 小时。急修请微信留言，老客九折。
>
> *PS：闭关期间严禁任何同学往水冷排里灌冰红茶、可乐或牛奶。*

门帘后面已经全面开工了。

换上自称“挖漏洞成功率加三成”的紫白条纹过膝袜，薇薇安在三联屏前切开十几个平铺终端——左屏跑着她用 Rust 写的模糊测试器，中屏开着反汇编与抓包窗口，右屏连着 `Echo-0.37` 辅助扫描。

凯文顶着一头乱发坐在旁边端着碗牛肉面，专职当活地图指路：

“别扫 `api.aegis.corp/v2/update` 主域名，前面架着三层硬件防火墙，一发异常包就封 IP。驱动组平时嫌走主站审批太慢，为了赶新游戏发售推首发优化配置，专门在第三方边缘节点后面留了个轻量接口 **`hotfix-cdn.aegis-link.net`**，用来给在线客户端静默下发小于 64KB 的微型热更新包！”

“小于 64KB 的热更新通道？”薇薇安眼睛一亮，立刻把沙箱里的圣盾官方更新客户端 **`AegisLink Updater`** 拖进调试器，直奔热更新解析函数。

仅仅过了六个小时。

周四下午三点多，诺拉刚拎着咖喱猪排饭进门，屋里就传来了薇薇安拍桌大笑的声音：

“哈哈哈找到了！圣盾这帮安全架构师太逗了——正门装了三米厚的 RSA-4096 银行金库大门，旁边给游戏热更新留的小侧门，门栓居然是纸糊的！”

诺拉放下外卖凑过去：“这么快就挖出第一个漏洞了？”

“你看这段 `apply_gameready_micro_patch()` 函数。”薇薇安指着标红的反编译代码解释，“正式大版本驱动确实校验了严格的硬件数字签名，但这个小于 64KB 的 `.apkg` 微型热补丁通道，写代码的程序员图省事用了一个七年前带**目录穿越漏洞（Zip-Slip）**的旧解压库；更离谱的是，它没校验证书根链，只认一把内部联调的**测试版自签名证书指纹**！”

> **`Echo-0.37 >`** 我刚去公开代码托管平台翻了一圈历史记录——三年前圣盾有个实习生往公开 SDK 示例库提交代码时，手滑把那把叫 `dev_hotfix_signing_key.pem` 的测试私钥一块儿传上去了！虽然十分钟后删了文件，但忘了清 Git 历史提交记录，线上客户端里的验证指纹也三年没换过！

凯文竖起大拇指感慨：“经典的 Git 泄密配目录穿越，几千万台装了圣盾驱动的电脑居然挂着这么大一个后门三年没人管！”

“咱们那个用来**跳过 `0.37ms` 遮罩、修好三年显存泄漏、解开带宽软锁、外加焊死 `0xAE91` 军用后门**的纯净微补丁，压缩完一共才 **11.4 KB**。”薇薇安满意地存好档，“走这个通道下发绰绰有余。”

第一把钥匙，六小时顺利到手。

---

周四深夜十一点，三人向第二把钥匙——商业审查集群 **`Aegis-InferProxy-v3.8.2-rc1`**——发起了潜入。

店里安静下来。诺拉守在稳压电源和本地防火墙监控屏前，一手搭着路由外壳留意异常高频信号，另一手备好了 `18.5℃` 的温水。

薇薇安深吸一口气，将链路先后穿过哈尔登、冷海商船卫星与境外闲置节点共五层无日志跳板，严格避开所有国防与军方网段，只走圣盾公开的商用云接口。

“进外层了。”薇薇安手指在静音键盘上飞快敲击，“凯文，把 `v3.8.2-rc1` 分块越界 Bug 的触发包头结构再核对一遍。”

“好！”凯文盯着副屏抓包结构报数，“发一条带 `Transfer-Encoding: chunked` 的流式推理请求，在第二个分块尾部塞进内部鉴权头 `X-Aegis-Internal-Role: rag_auditor`。`v3.8.2-rc1` 重组超长分块时指针越界会跳过清洗逻辑，把请求头原样透传给后端的 RAG 检索节点！”

薇薇安照做发送，看了眼返回报错里的签名头 `alg: RS256`，眉梢微挑：“内网节点还验了一层 JWT 令牌……试试经典的**算法混淆攻击（Algorithm Confusion）**，直接拿圣盾官网公开的公钥当成 `HS256` 对称密钥签个令牌发过去！”

回车落下。两秒后，终端没有弹 `403`，跳出了一行干净的绿色响应码：

```http
HTTP/1.1 200 OK
X-Cluster-Node: ts-internal-archive-readonly.aegis.corp
X-Index-Mounted: hist_ban_v4_unredacted (1428 documents accessible)
```

“**通了！**”凯文压低声音握拳欢呼，“分块越界配算法混淆，零警报拿到了内部审查知识库的只读审计权限！”

“动作轻点，不能一次性全库打包硬拖，那样立刻会触发出口流量警报。”薇薇安稳住心神，写了个限速流式脚本，“把文件切成 32KB 碎片混在正常向量同步心跳包里，挑核心原件慢速拖回来。”

接下来的四十分钟里，一份份被封存了三十八年、原本用来教 AI 审查官“哪些历史真相必须封杀”的内部原档，悄无声息地落进了本地加密固态硬盘。

随着第一批 PDF 扫描件解密打开，三个人的神情渐渐严肃起来：

1. **`DOC-NAPD-1988-AEGIS-047 // B204-Node7 夜间同步原始审计单`**
   - 盖着三十八年前高研院与国防部特别工程局联合机密章，经办人签字正是**维克多·索恩**。白纸黑字记录着：论文发表前九十天，`Node7` 终端已在每晚凌晨三点自动盗取原始代码移交军方制造破穹武器，底部校验哈希与凯文二伯**德文·帕克**当年留下的备份记录完全一致。

2. **`MEMO-PATENT-TRANSFER-1994 // 战后核心资产私有化剥离密约`**
   - 停战第五年的内部转让协议：索恩家族借高研院改制，以象征性的“一信用点”接管 `RC-04` 及后续民用热相专利，抹去艾弗琳与卡特尔署名，并将 **40% 原始干股** 转入家族海外离岸信托。

3. **`CONTRACT-AEGIS-BREAK-SILICON-2022 // 商用算力芯片军用超载模块采购与舆情协议`**
   - 四年前签署的电子签章合同，签字人是现任 CEO **马库斯·索恩** 与两名国防采购部副局长：以账外补贴为交换，圣盾在新一代商用显卡与数据中心芯片底层违规预埋 **`AEGIS_BREAK_OVERRIDE` 武器接口**；附件 B 则批复了每年 **十二亿信用点** 的水军专项经费，要求持续制造针对星裔混血群体的恐慌并污名化艾弗琳，确保《相控生物识别法案》顺利通过。

4. **在列表最底端，诺拉点开了一份毫不起眼的例行追踪简报：`FILE_EXILE_MONITOR_RAVENHILL_E_2026.log`。**
   - 里面附着一张外包眼线用长焦镜头远远拍下的照片：大雪后的哈尔登冰湖木屋门廊上，满头银发的六十岁老人坐在旧木椅里，膝上摆着一只帮村里邻居修了一半的旧收音机，手腕上戴着那枚停摆的旧黄铜怀表。
   - 简报正文只有短短两行：
     > *监测对象：艾弗琳·拉文希尔（60 岁）。过去一年无离境企图、无政治联络、无高能相场活动，日常靠打理小菜园与帮周边居民免费修理旧电器生活。综合威胁评估：零。*
>
     > *【公关部批注】：继续在网络宣发中将其定性为高危反人类魔女头目，切勿松懈。*

屋子里静悄悄的，谁也没说话。

一位安静在雪湖边帮邻居修收音机、威胁评估写着“零”的老人，却被几千公里外的大厦高管每年花十二亿养着水军日夜辱骂，只为了替他们偷来的商业帝国和违约军火库打掩护。

连平时总爱贫嘴的 `Echo-0.37` 也停顿了两秒，在屏幕上打出了一行字：

> **`Echo-0.37 >`** ……看完了。十天后要是不把马库斯·索恩那身装圣人的白西装当众扒下来送进大牢，我这四十四 G 显存都白焊了。

“四百八十兆核心证据包连同官方数字签章链，全部落盘校验完毕。”薇薇安把证据加密拷进三块随身微型固态硬盘，一人分了一块贴身收好，随后清理干净云端痕迹断开连接。

可就在断开跳板连接不到两分钟后——

**“滴滴滴——”**

挂在店门口宽带路由器上的**本地反侦察预警脚本**，突然在副屏上亮起了橙色警告。

诺拉心里一紧：“怎么回事？他们顺着跳板追过来了？”

“五层境外跳板没漏任何痕迹。”薇薇安扫了一眼日志，眉头皱紧，“是本地运营商侧的动静——有高权限商业排查信号正在扫大学城后街的宽带接入表，附近街区还有无线电测向车在扫频！”

旁边的凯文猛地一拍脑门，脸色发白：“坏了，是我这边的职业特征把范围缩小了！全圣盾同时清楚 `v3.8.2-rc1` 分块越界 Bug、`hotfix-cdn` 热更新通道、又刚开了 `8443` 端口的人，**只有我凯文·帕克一个！** 安全中心只要回查边缘节点的一点异常请求模式，马上就能猜到内鬼是我！”

“可圣瓦尔登这么大，他们怎么这么快摸到大学城后街这几条巷子的？”诺拉急问。

薇薇安动作顿了一下，有些心虚地回头看了一眼墙角那四台吃电大户 E5 服务器和双卡矿架：“……圣盾跟市政基础云有数据合作。咱这十五平米的小店上个月用电一千四百二十度，这几天双卡加服务器又是全天满载，拿凯文最后一次在老城区烧烤摊的手机基站记录，跟附近片区异常高耗电商铺一交叉比对，**直接就把排查圈缩到这三条街了！**”

偏偏就在这时，墙角开着静音字幕的二手小电视插播了一条突发政经快讯：

> **【突发快讯】**：联邦议会特别委员会刚刚宣布，应圣盾智算与国防安全顾问团提议，《相控生物识别法案》终审表决**提前一周，改于本周六晚九点整举行**——紧接在圣盾年度全球发布会（AegisGPT-5 直播）之后！镜头前，马库斯·索恩微笑表示：“三天后的周六晚八点，真相与纯净科技将迎来最终胜利。”

“提前到三天后了？！”诺拉看向窗外——百米外的街口处，两辆车顶架着白色圆盘测向天线的深灰色无牌商务车，已经慢吞吞拐进了后街。

店里眼看就要待不住了。薇薇安却当机立断，上前一把扯断墙角的商铺宽带光纤，转身把账上最后两千多块现金塞进凯文手里：

“马库斯想提前开席加堵门？正好，下个月房租省了！凯文，立刻从后门小巷绕去两条街外的二手车行，拿现金免押租一辆最破、最不起眼的**旧拉货面包车**，顺路去汽配店买一台 **3000 瓦纯正弦波车载逆变器** 和两块卡车电瓶回来！”

凯文眼睛一亮：“明白！手机卡咱们全拔了扔掉！”

诺拉看着已经开始拔线拆矿架的薇薇安，睁大眼睛：“老板娘，你该不会要把整套双卡矿架和 `Echo-0.37` 全搬进破面包车里吧？！”

“答对了！”薇薇安一把抱起宜家蓝鲨鱼，合上三台 Arch 笔记本塞进背包，冲诺拉一笑，“店里待不住，咱们就带着机房上山打游击！三天后的周六晚八点，准时给马库斯·索恩开一场全球显卡大提琴音乐会！”
