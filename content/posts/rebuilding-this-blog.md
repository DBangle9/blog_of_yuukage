这个网站最初用来存放原创角色设定、插画和故事。现在，它将逐渐成为一个更完整的个人博客：可以写技术实践，也可以写经验和杂谈。

## 为什么重新整理

个人创作是这个站的起点。随着记录的内容变多，网站也需要更清楚的组织方式。读者来到这里，应当能方便地找到文章、了解站点作者，或者继续探索感兴趣的主题。

这次改版把博客文章放到了首页。旧站的故事、角色设定和画廊仍保留在「创作归档」中，已有故事的地址也保持不变。

## 这里会记录什么

- **技术实践**：搭建、调试和解决具体问题的过程。
- **经验与复盘**：做过的尝试、遇到的限制，以及可以改进的地方。
- **日常思考**：阅读、生活与个人观察。

技术文章尽量写清问题、环境、操作过程和验证结果；杂谈则允许保留个人视角。两者都以清楚、诚实的表达为目标。

## 如何维护

新版继续使用 Hugo。文章以 Markdown 文件保存，网站由静态文件组成，不需要额外维护文章数据库。

修改内容后，可以先在本地预览，再生成发布文件：

```sh
hugo server -D
```

正式构建时使用：

```sh
hugo --minify --gc
```

`-D` 只用于本地查看草稿，正式构建不带这个参数。

每篇记录都有单独的地址，可以通过标签查阅，也可以搜索正文。喜欢用阅读器的人，可以订阅[文章 RSS](/posts/index.xml)。

站点目前准备迁移至 Cloudflare Pages。正式上线后的维护记录，会随着实际部署和使用继续补充。

## 接下来

与其先堆满页面，不如从一篇解决实际问题的记录开始。这个博客也会随着内容的积累，逐步形成自己的样子。
